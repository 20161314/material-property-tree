# 物体表与材料树循环扩充共同规则

版本：2026-11-13。适用于来源身份库存、组件材料标签、材料研究范围及网站发布。

## 采集优先级

优先柔性材料及含柔性组件的物体；硬性材料与硬性物体继续批量采集。鞋、包等类别只用于检索排序，不等于整件柔性，也不证明具体成分。不为凑比例创造材料标签。

## 物体和组件

1. 冻结清单、版本、来源及 SHA-256。采集者写独立包，单一合并者修改共享主表。
2. 按官方可枚举稳定资产 ID 建行，记录可读中文类名、原英文名、来源、许可和资产链接。论文汇总数、图片数、增强数不生成对象行。类别翻译不能冒称完整商品名翻译。
3. 先核来源别名，再做文件哈希和几何去重。未完成内容去重时称“来源对象身份”，不称全局唯一几何。
4. 采用官方 part/prim ID、独立几何及物理结构确认真实组件。材料池、外观槽、祖先节点、重复引用不自动生成组件。没有可靠分件时保留 WHOLE 整件占位，明确尚未枚举全部部件。
5. 粗细材料标签均可，优先保留有支持的细标签。合理近似单独记录依据、范围及状态。不同材料配置不增加几何数；材料替代选项与同时存在组分分开，不生成笛卡尔配置。
6. 来源文本描述的鞋面、鞋底等材料范围可以作为回链，但不虚构对应网格组件，不自动继承数值物性。

## 物性与材料树

1. 完整与缺项同步收集。同一来源组 E、ν、ρ 三项齐为一完整组；一项或两项为一缺项组。同文真实多组分别保留；不拆属性、区间端点、重复表格或镜像来增量。
2. 可收原文实验、基于真实测量的作者推导、明确引用的材料值及厂家典型值，保留其性质。仅模型/仿真输入、solver 默认和 AI 生成数值不入来源研究账。缺项不填 0。
3. 同材料的官方汇编可保留各属性原引用，标为来源汇编完整组，不能冒称同试样实测。不跨项目文件或材料身份拼造完整组。
4. 以树种、牌号、化学体系、配方、增强及真实构造细化节点；颜色、温度、方向、重复号通常保作条件。基材、涂层、纤维、织物、泡沫及整复材不混同。
5. 只有已审查包含关系才能把细节点证据向父节点研究范围汇总。不向下继承，不从同族材料补具体目标缺口。证据节点可以暂时没有物体。
6. 密度定义、模量方法、原单位、换算、条件、原值、文献位置、文件 SHA 和局限逐条保留。面密度、强度、比模量不能替代体密度或杨氏模量。
7. 研究范围与正式可赋值属性分开。范围有数值不自动证明某个产品或组件使用该材料。

## 双向循环与发布

1. 新材料产生物体/组件检索任务；新对象产生部件、材料标签和物性来源任务。缺首值、缺属性、缺更多来源和分类问题分别排队。
2. 稳定任务 ID 保存触发原因、优先级、已尝试路径、状态及下一步。柔性优先，硬质采集保持活跃。
3. 发布前核旧行保留、批准增量精确 ID、文件 SHA、真实组件替换、分类无环、单位解析、空值、页面计数、引文、分页及资产路径。
4. 本地与 GitHub 分别记录版本。推送后核 Pages 状态及公开 payload；失败不得称已部署。
5. 执行有限批次并保存队列；队列存在不代表关闭对话后自动运行。新来源需有适配器与审查包，不能声称支持任意数据集。

## 统计口径

- 来源对象身份、内容去重几何、不同对象组件对、映射/状态行及材料配置分别统计。
- 材料数动态更新。粗细节点并存，不是互斥材料类别；组织节点、非材料特殊域、外库未规范化组成身份单列。193 仅是历史追踪视图。
- 完整组、缺项组、文档键、独立来源谱系及发布主体分别统计。数据库转录与原文回读分层，不把文件数当独立文献数。
