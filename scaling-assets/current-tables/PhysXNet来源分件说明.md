# PhysXNet来源分件附表

本附表补来源几何分割信息，不能与已验证机械组件直接相加。

- 140,041个来源part键对应ZIP中OBJ路径，覆盖24,946个已有几何身份；1个缺OBJ的Tube部件隔离。
- 4个几何只有非主ID别名注释，另367个缺全部已知ID注释；未随意挑别名替主版本。
- 生成材料标签仅原样披露候选；全部生成E/ν/ρ排除，不进文献物性账。
- 已核中心目录、JSON CRC/长度、part键与OBJ目录对应；OBJ文件本体未下载，不能称几何SHA已验证。
- stable对象ID来自现有25317清单；不把32047注释版本当新增几何。
