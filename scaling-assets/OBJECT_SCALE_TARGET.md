# 物体规模与格式执行约定

更新日期：2026-11-14。用户目标：物体库最终扩充到 **100,000 个以上几何物体**，保留物体及对应部件的层级；该目标不表示当前已完成。

1. **三级结构**：几何物体 → 来源可核实的部件 → 每个部件的材料标签或明确标注的材料备选。物体保留中英文名称、来源名称、来源记录链接及3D资产/整包下载路径。材料存在多个备选时逐项保留，不生成材料笛卡尔积。
2. **分别计数**：来源对象身份数、几何内容已核验数、已发现跨源重用/重复数、真实来源部件数、WHOLE整件回退数及材料化变体数分别报告。当前来源对象数不能直接表述为全球几何去重后的唯一模型数。
3. **不能凑数**：视图、纹理、颜色、文件格式、同资产镜像、LOD或同一几何的材料变体不增加几何物体数。跨来源已知重用保留别名和来源成员关系；暂未完成内容去重的记录明确标识其状态。
4. **部件边界**：有源part ID、几何引用或作者明确物理结构时按证据记录。未提供分件的模型可以进入整件索引，但必须标为WHOLE/来源未分件，不能宣称已取得完整部件。渲染mesh、材质槽和分割标签均不自动等同机械部件。
5. **材料与物性边界**：材料标签可使用来源声明或用户允许的合理近似，来源性质和范围必须显式记录。E、ν、ρ仍只采用真实文献或官方资料中的数值，不采用生成值或仅仿真输入；不为新增资产自动下推材料牌号或数值。
6. **两条并行路线**：为三项有来源值但无物体的材料找真实资产；同时从可枚举的官方大规模资产清单扩充物体与部件。优先增加柔性和混合材料物体，并持续扩充硬物体。
7. **发布门禁**：候选、已枚举来源记录、下载核实、材料关联通过、已合并及已发布分别记录。只有已审核合并的增量进入正式计数。保留旧记录和原始证据，三页网站从同一版本重建。
8. **规模计划**：以当前已核实发布为基线，逐来源导入并报告真实净增；不凭论文声称数量生成物体。目标未达成时直接报告差额与剩余工作，不把排程描述为已完成或后台持续运行。
