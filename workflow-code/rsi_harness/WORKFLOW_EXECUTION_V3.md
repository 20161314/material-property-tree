# RSI 可执行工作流 v3.1

更新：2026-11-20。当前机器规则为 `config/rsi_workflow_v3.json`。所有程序步骤已有执行入口；需要语义判断的步骤已接入模型文件交接。实现完成与本轮数据审核完成分别记录。旧 `RSI_WORKFLOW_DETAILED_2026_11_20.md` 中“只有计划器”的边界已由本文取代。

## 执行顺序

1. 固定原始资料和当前版本。建立新的运行目录，保存输入 SHA、规则、父版本、运行预算；正式表、历史包及已发布网站只读。
2. 解析来源清单。CSV、TSV、JSON、JSONL、gzip 使用显式字段映射，保留原字段。仅稳定资产编号形成对象；论文总数与缺失清单进入缺口。
3. 核验文件并去重。先检查下载内容和 SHA；HTML/XML 错误页不能冒充 GLB。只依来源编号、经审核别名及可靠载荷证据合并；相同名字不自动合并。
4. 展开部件。只有来源明确提供的部件、prim 或网格分组才能展开；没有结构的记录保留“整件（未拆分）”。部件不计作新物体。
5. 形成材料关系候选。保留来源标注、数据集规则、模型输出与合理推定的区别。区分局部材料、互斥材料及数据集风格选项；不组合膨胀几何数量。
6. 独立审核材料关系。默认100条，允许50–200条，尾批注明实际数。指定 `gpt-6-luna/max`；身份、单位、关系歧义单独交 `gpt-6.1-sol/high`。每条均有结论、原因和冻结来源定位。
7. 规范材料并审核分类。原词与规范名均保留。仅通过的 `IS_A` 边进入分类图；别名、用途、组成不能冒充父子包含关系。细粒度名称优先，但必须有来源支持。
8. 逐层安排任务。代码计算树层及材料四类状态；物体扩展仅从三项分别有来源值的 S1/S2 节点出发。材料任务同层优先补现有物体使用但缺项的节点，随后处理完整但无物体的节点。软材料可提高同层、同优先级轮转权重。
9. 收集并提取物性。完整组和缺项组同时保存。同一材料结果组中有 E、ν、ρ 是完整组；有一或两项为缺项组。条件未知仍保留；数值不能来自模型、仿真输入、求解器默认值或父类猜测。
10. 独立回读数值。逐项对应属性、数值、单位和来源位置，保存方向、密度定义、样品条件及方法。一个文献的多组结果分别保存，但独立来源数不随组数增加。
11. 合并。唯一合并程序检查父版本、输入及候选 SHA、实际模型交接回执、独立审核与精确修改前像。只应用 PASS 的明确增量。HOLD/REJECT 保留内部原因。SQLite 事务失败整体回滚；同一事务重跑返回原回执。
12. 重算及对账。对象、部件、关系、材料、完整组、缺项组、文献分别计数。只沿批准的分类边向上汇总，按对象编号及来源记录编号去重；不得向子材料复制父类数值。
13. 构建新候选四页。`workflow_projection_v3.py` 直接消费合并器导出的六表数据包，用同一个版本生成物体分片、材料树、来源对照及工作流；原站只提供样式和交互代码，统计不沿用旧站。只有展示层更新时才调用 `workflow_publication_v3.py build-site` 保持原数据。公开物体、部件、材料、依据和来源；隐藏内部字段、路径、哈希、安装及审核流水。缺值写“未提供”。
14. 验证并发布。全面完成版必须通过原完整发布门禁；研究进展快照须通过已有研究快照合同并明确保留未完成事实。真实浏览器检查四页、桌面及手机，随后精确批准候选并检查远端父提交；用非强制方式发布，再回读远端文件和线上页面。
15. 下一轮。保存未解决任务、材料修订号、尝试次数、已用时间与来源路线。新版本使旧父版本的任务失效，不能沿用旧审核回执。

## 模型与程序的职责

推进代理负责调度、查看回执、处理异常和监督进度。重复解析、分批、去重、任务领取、覆盖计算、事务及发布检查均由程序执行。

一般来源研究、分类及歧义处理使用 `gpt-6.1-sol/high`；批量独立审核使用 `gpt-6-luna/max`。指定模型不可用即停止该任务，不静默替换。模型任务通过冻结的 JSON 文件交接，不携带整个聊天历史。宿主工具完成实际调用后，记录可核对的调用与代理编号；客户端自己填写的模型字符串不能证明发生了真实调用，必须结合宿主调用日志核验。

采集结果只能成为 `CANDIDATE_READY`。独立审核后成为 `REVIEWED`；唯一合并程序写入后成为 `MERGED`。提交候选、审核通过、写入数据、发布网站和全部完成是不同事件。

## 输入与输出标准

标准数据包必须有六张表：`objects`、`components`、`materials`、`relations`、`taxonomy`、`evidence`。原始输入与当前项目旧格式由适配器转换；不直接重写旧表。

| 表 | 主键与必要内容 |
| --- | --- |
| 物体 | object_id；原来源编号、中英文名、资产/整包链接及许可在原字段中保留 |
| 部件 | component_id、object_id、scope、source_locator；区分真实部件与整件回退 |
| 材料 | material_id；中英文名、粒度及排除范围保留 |
| 材料关系 | relation_id、component_id、material_id、decision；PASS 必有依据、来源定位和独立审核者 |
| 分类 | edge_id、child_id、parent_id、relation、decision；只有 PASS 的 IS_A 用于上溯；必须无环 |
| 物性 | record_id、material_id、document_id、source_group_id、origin、properties；PASS 必有原文、定位、来源 URL 和独立审核者 |

每个物性字段使用 `{value, unit}` 或 `{lower, upper, unit}`。E 支持 Pa/kPa/MPa/GPa，密度支持 kg/m³ 与 g/cm³，泊松比无量纲。原值及方法保留；不把误差自行当范围。每组至少一项数值，E及密度为正，范围不可倒置，非数值与无限值不得进入可计算覆盖。未解析原文保留在候选包，不能伪装为已标准化数值。

每个任务保存父版本、epoch、输入及候选 SHA、步骤、路由、采集者、处理者、attempt 与任务锁。每条审核只允许 PASS/HOLD/REJECT，必须覆盖所有分配记录一次；来源定位必须来自冻结输入。调用回执与任务、父版本、attempt、epoch、任务锁及实际代理绑定，同一调用编号不能重复使用。采集者不得审核自己，合并者不得充当该批采集者或审核者。

## 四类状态与范围

| 状态 | 三项各有来源值 | 有关联物体 |
| --- | --- | --- |
| S1 | 有 | 有 |
| S2 | 有 | 无 |
| S3 | 缺至少一项 | 有 |
| S4 | 缺至少一项 | 无 |

三项可来自不同文献；完整组数量另算，不能跨文献拼成完整组。细材料的物体及证据可沿批准的 IS_A 归入粗材料，反向不允许。液体、空洞、组织性分类及特殊域退出活动固体分母并保留历史。

每项属性尽量达到五份独立来源；这是增强目标，稀缺资料不因此被删除。有来源值的细粒度节点即使没有物体也可以保留，并反馈给物体扩充队列。“暂未找到”不能写成“绝对不存在文献”。

## 恢复与预算

每次任务最多900秒，剩余预算不足时缩短任务锁；并行领取时预留预算，避免超额分配。每任务最多三次尝试，过期任务需明确恢复，第三次失败进入冷却。恢复保留已用预算与次数；同一任务不能被两个恢复者重复计费。模型输出只在有效任务锁与当前父版本下接收。

材料前沿按材料状态修订号持久保存，重复运行不重新领取已完成的同一修订。新版本推进会使旧任务变为 STALE，释放任务锁并保留历史；不得把过期任务标为已完成。

## 入口

```bash
python3 rsi_harness/workflow_plan_v3.py --validate
python3 rsi_harness/workflow_run_v3.py --help
python3 rsi_harness/workflow_publication_v3.py --help
python3 rsi_harness/workflow_inventory_v3.py --help
python3 rsi_harness/workflow_projection_v3.py --help
PYTHONDONTWRITEBYTECODE=1 python3 rsi_harness/workflow_verify_v3.py
```

`freeze` 创建隔离运行；`enumerate/dedup/components/payload` 处理来源与结构；`batch/claim/dispatch/candidate/review-batch/submit` 完成模型交接；`merge/state/reconcile/bfs/checkpoint/export` 管理数据与下一轮。投影器消费 `export` 生成新数据网站；发布适配器提供 `build-site/validate-site/browser-check/publish-site/verify-remote`。新数据网站必须有数据和展示两方面的独立审核，单纯代码审核不构成数据发布批准。网站按钮只用于查看流程，不会从浏览器直接调用模型、修改数据库或发布。

模型调用须由具有相应权限的宿主工具发出；Python 执行器不会自行购买 API 服务或读取未声明的凭证。当前验证使用隔离的合成测试记录，不能视为真实材料或物体被模型审核。
