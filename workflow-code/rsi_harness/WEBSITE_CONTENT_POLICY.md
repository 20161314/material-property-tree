# 网站内容规则

适用范围：物体总览、材料树、物性来源对照及它们的详情页面。

- 保留用户认可的现有网页样式。内容修改不顺带重新设计配色、布局或导航。
- 网页采用中文字段名和简明用语。数据集名、材料牌号、专业缩写、原文标题及链接保留原写法；需要引用原文时明确标为原文。
- 物体详情优先展示：物体名称、部件名称、材料标签、标签依据、来源链接、3D 资产或整包下载地址。没有源部件划分时写“整件（未拆分）”，不编造机械零件。
- 材料标签区分“来源标注”“合理推定”“可选材料”“局部材料”“数据集材质选项”。可选材料不得改写成同时组成；数据集风格选项不得改写成实物成分。
- 网站展示入口只消费已批准的数据和有效关系。候选、暂缓及拒绝关系留在内部账，不进入已接受标签。合格物体可以暂缺材料；直接说明缺项，不能用候选标签填满。
- 不展示内部字段、审核流水、队列编号、本地绝对路径、校验码、安装状态或重复的赋值禁令。内部保留原字段、来源定位、审核结果与哈希，网页的精简不删除研究记录。
- 物性详情优先展示：材料名称、杨氏模量 E、泊松比 ν、密度 ρ、单位、来源、原文位置。方向、密度定义、样品条件、统计量和不确定度会影响数值含义，放在可展开的“条件与方法”中保留。
- 完整组和缺项组分别计数；不同资料的单项值可以支持三项覆盖，不能拼成同源完整组。缺值显示“未提供”，不写 0。
- 网站已消费批准数据，不在每条记录重复“已审核”。数据库转录尚未逐篇回读等事实用一次简短说明保留，不能通过删文案制造已逐篇复核的印象。
- 发布前批量核对全部物体编号、部件归属、材料外键、来源、展示范围、重复关系和数值保真；另做浏览器验收。结构检查通过不能声称逐一验证了所有实物的真实成分。
- 只报告实际完成的检查、公开排除项和仍待解决的问题；所有页面使用同一快照。
